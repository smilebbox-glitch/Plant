# MGC Plant — симулятор завода MGC (Калуга)

Браузерная изометрическая 3D-игра: вы директор автозавода MGC в Калуге. Штамповка → сварка → окраска → сборка → ОТК → отгрузка дилерам, склад, логистика, погрузчики, персонал, кризисы.

Языки: русский, English, 中文 — переключатель в верхней панели (или `?lang=ru|en|zh` в адресе).

## Состав

| Файл | Что это |
|---|---|
| `index.html` | Вся игра в одном файле |
| `vendor/three.min.js` | Three.js r128 (локальная копия, чтобы игра работала без интернета) |
| `Dockerfile`, `docker-compose.yml` | Запуск на сервере через nginx |

Интернет игре не нужен. Если он есть, подгружаются шрифты Onest с Google Fonts; без него используется системный шрифт. Если `vendor/three.min.js` недоступен, страница сама возьмёт Three.js с cdnjs.

## Запуск на сервере (Docker)

```bash
git clone https://github.com/smilebbox-glitch/plant.git
cd plant
docker compose up -d --build
```

Игра откроется на `http://<адрес-сервера>:8090/`. Порт меняется в `docker-compose.yml` (строка `"8090:80"`).

Обновление до новой версии:

```bash
cd plant
git pull
docker compose up -d --build
```

## Запуск без Docker

Подойдёт любой веб-сервер, отдающий статические файлы из папки, например:

```bash
cd plant
python3 -m http.server 8090
```

Можно открыть `index.html` и просто двойным щелчком — игра запустится, но сохранения в некоторых браузерах для `file://` работают хуже, поэтому для постоянной работы лучше сервер.

## Сохранения

Прогресс хранится в браузере игрока (localStorage) — у каждого сотрудника и на каждом компьютере свой. На сервере ничего не хранится, база данных не нужна.

Браузеры: свежие Chrome, Edge, Firefox, Яндекс Браузер. Нужна поддержка WebGL.
